# `EmbedViewer.tsx` — Page Documentation

> **Location:** `src/pages/EmbedViewer.tsx`  
> **Type:** React Page Component (default export) — TypeScript/TSX  
> **Route:** `/embed/:id`  
> **Purpose:** A minimal, public-facing iframe-embeddable read-only canvas view of a schema. Fetches the schema by ID from Supabase (only succeeds if `is_public = true`), loads it into the schema store, and renders `SchemaCanvas` in read-only mode. Includes a "Powered by Modellr" branding overlay for viral growth. No nav, no toolbar, no editor chrome — canvas only.

---

## File Overview

`EmbedViewer` is the **embed target** for the `<iframe>` snippet generated by `ShareModal`'s "Publish & Embed" tab:

```html
<iframe src="https://Modellr.io/embed/{id}" width="100%" height="600" ...></iframe>
```

It is intentionally stripped down — no `TopBar`, no `Sidebar`, no `StatusBar`, no overlays. The entire page is:

```
Loading…                → while fetching
"Access Denied" screen  → on error or private schema
Full-viewport SchemaCanvas + branding badge  → on success
```

## Effect — Fetch & Load Schema

```ts
useEffect(() => {
  setReadOnly(true);   // Enforce read-only immediately, before fetch completes

  async function fetchSchema() {
    if (!id) {
      setError("Invalid schema ID");
      setLoading(false);
      return;
    }

    const { data, error: sbError } = await supabase
      .from('schemas')
      .select('name, canvas_state, is_public')
      .eq('id', id)
      .single();

    if (sbError || !data || !data.is_public) {
      setError("This schema is either private, does not exist, or you lack permission to view it.");
      setLoading(false);
      return;
    }

    setProjectName(data.name);

    if (data.canvas_state) {
      const state = typeof data.canvas_state === 'string'
        ? JSON.parse(data.canvas_state)
        : data.canvas_state;
      if (state && Array.isArray(state.tables)) {
        importTables(state.tables, state.relationships || []);
      }
    }

    setLoading(false);
  }

  fetchSchema();
  return () => setReadOnly(false);   // Cleanup on unmount
}, [id, importTables, setProjectName, setReadOnly]);
```

### `setReadOnly(true)` — Immediate, Before Fetch

Read-only is set **synchronously before the fetch begins** — the canvas is in read-only mode from the first render, even during the loading state. This prevents the brief window where a user could theoretically interact with the canvas before the fetch completes.

### Supabase Query

```ts
supabase.from('schemas')
  .select('name, canvas_state, is_public')
  .eq('id', id)
  .single()
```

Selects only the three fields needed — not `SELECT *`. Supabase RLS's `is_public` policy means:
- If `is_public = false`: RLS returns no rows → `data` is `null` → error state
- If `is_public = true`: row returned and rendered

The component also explicitly checks `!data.is_public` after the query — a belt-and-suspenders guard in case RLS is misconfigured.

### Three-Level Access Gate

```ts
if (sbError || !data || !data.is_public) {
  setError("This schema is either private...");
  ...
}
```

All three cases map to the same "Access Denied" message — the user cannot distinguish between "schema doesn't exist," "schema is private," and "RLS error." This is intentional security practice (no schema enumeration), but it means a legitimate public schema that fails due to a network error shows the same message as a private one.

### `canvas_state` Parsing

```ts
const state = typeof data.canvas_state === 'string'
  ? JSON.parse(data.canvas_state)
  : data.canvas_state;
```

Same guard as `handleExport` in `Dashboard.tsx` — Supabase `jsonb` columns may be returned as a raw string or a parsed object. Handles both.

```ts
if (state && Array.isArray(state.tables)) {
  importTables(state.tables, state.relationships || []);
}
```

`state.relationships || []` — safe fallback if the canvas state predates the relationships field or has an empty schema. `importTables` replaces the full store state with the fetched data.

### Cleanup

```ts
return () => setReadOnly(false);
```

Resets `readOnly` when the component unmounts. In the embed iframe context, unmounting rarely happens (the iframe stays loaded). More relevant if the component is ever rendered outside an iframe (e.g. during testing).

## `SchemaCanvas` in Read-Only Context

`SchemaCanvas` renders the same React Flow canvas as the full editor, but in read-only mode (`readOnly = true` from `useUIStore`). This means:

- Table nodes are not draggable (or drag changes are rejected)
- No right-click context menus
- No field editing
- React Flow's built-in pan and zoom still work (user can navigate the canvas)
- `MultiplayerCursors`, `TopBar`, `Sidebar`, `StatusBar`, `RightPanel` are all **absent** — not mounted

The full editor's `Editor.tsx` renders `SchemaCanvas` inside a complex shell; `EmbedViewer` renders it alone in a `100vh × 100vw` container.

## Notable Patterns & Caveats

| | Detail |
|---|---|
| **No auth required** | `EmbedViewer` makes no auth check — public schemas are freely accessible. Auth is RLS-enforced at the DB level |
| **Global store mutation** | `importTables` + `setProjectName` + `setReadOnly` mutate the shared Zustand store. In normal app flow this is fine; if `EmbedViewer` is somehow rendered alongside another editor instance (it shouldn't be), the stores would conflict |
| **No `notes` or `groups` loaded** | `importTables(state.tables, state.relationships)` — notes and groups from `canvas_state` are silently ignored (not present in `importTables` signature) |
| **`canvas_state` could be `null`** | If the schema was just created and never edited, `canvas_state` is `null` — the `if (data.canvas_state)` guard shows an empty canvas rather than erroring |
| **All errors show the same message** | Network error, private schema, and non-existent schema are indistinguishable from the user's perspective — intentional for security |
| **No loading animation** | "Loading schema..." is plain text with no visual indicator of progress |
| **`Modellr.io` hardcoded in branding badge** | The link href is hardcoded — if the domain changes, this must be updated manually (unlike other URLs that use `window.location.origin`) |
| **`setReadOnly(false)` on unmount** | Correct cleanup but unnecessary in iframe context where the embed page is never navigated away from |
| **`import('../utils/templates')` not used** | Unlike the sandbox, `EmbedViewer` doesn't pre-load a template for empty schemas — just shows a blank canvas |
| **Supabase `anon` key allows public reads** | The embed works without the user being logged in because the Supabase client uses the `anon` key + RLS. The `anon` key is exposed in `VITE_SUPABASE_ANON_KEY` — expected and safe for public read-only access |

## Embed Lifecycle — How It Connects to `ShareModal`

```
ShareModal (Embed tab)
  ├── Toggles is_public = true via Supabase UPDATE
  └── Shows <iframe src="/embed/{id}" ...>

         ↓ parent page renders the iframe ↓

EmbedViewer (route: /embed/:id)
  ├── setReadOnly(true)
  ├── supabase.select('name, canvas_state, is_public').eq('id', id)
  │       └── RLS: only returns row if is_public = true
  ├── setProjectName(data.name)
  ├── importTables(state.tables, state.relationships)
  └── renders: <SchemaCanvas /> + branding badge
```
